# 参考资料说明

本目录记录公开知识库的资料来源和使用原则。

## 资料类型

公开文档主要参考以下材料：

- 已公开的产品介绍、演讲和技术文章；
- 正式产品定义、版本说明和用户手册；
- 经过确认的架构设计和测试报告；
- 标准组织、厂商官网、论文和开源项目文档。

内部需求、客户反馈、预算、工时、遗留问题和未发布计划只用于理解背景，不直接进入公开内容。

## AIOS参考论文

- Yingqiang Ge 等，《LLM as OS, Agents as Apps: Envisioning AIOS, Agents and the AIOS-Agent Ecosystem》：<https://arxiv.org/abs/2312.03815>

本知识库借鉴论文关于LLM、Agent、记忆、工具和自然语言接口的概念，但不把论文中的设想直接表述为鸿道当前已实现能力。

## 引用规则

1. 行业产品信息优先引用厂商官网、正式文档、论文或开源仓库。
2. 引用性能结果时说明硬件、版本、配置、负载、测试方法和日期。
3. 对外发布前确认产品名称、商标、认证、客户案例和数据的公开权限。
4. 对随时间变化的信息标注资料更新时间。

# 鸿道机器人操作系统公开知识库

本知识库用于整理鸿道机器人操作系统相关的场景、产品、技术、通信和行业调研，帮助读者从机器人任务链路逐步理解操作系统、三域融合、中间件和开发交付平台。

这里首先回答四个问题：

1. 机器人如何完成感知、决策、控制和执行？
2. 操作系统、ROS2和机器人中间件分别负责什么？
3. 鸿道如何通过智控域、运控域和通信主站域组织系统？
4. 行业中的代表性机器人平台采用了哪些技术路线？

## 能力状态说明

文档使用以下标签，避免把规划能力写成已经发布的能力：

- **当前基础**：已经形成产品基础，具体支持范围以正式版本资料为准。
- **开发验证中**：正在研发、适配或测试，尚不能代表全部平台均已支持。
- **演进构想**：产品方向或研究思路，不构成当前交付承诺。

## 内容原则

- 先解释用户和场景，再介绍技术组件。
- 只引用可以核实的产品事实和测试结论。
- 性能数据必须绑定硬件、版本、配置、负载和测试方法。
- 客户信息、预算、遗留问题和未发布计划不进入公开文档。
- ROS、Agent和AI模型属于产品生态或上层能力，不与操作系统内核混为一谈。
